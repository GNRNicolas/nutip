# Nutip

A folder of clips the user saved deliberately, one Markdown file each, plus a
`why` line: their intent, which nothing else in the folder carries. `nutip` is
the CLI over it. `nutip path` prints the folder, `nutip doctor` the setup.

## Read

Start with the index pages, not the files. They hold the date, title, source,
tags and `why` of every clip, which is usually enough to pick the two or three
worth opening.

```sh
nutip search "pricing #competitors" --json   # full text + tags, newest first
nutip search claude                          # same, plain text
nutip recent 20                              # what they saved lately
nutip tags                                   # the tags they use
```

`--json` gives an absolute `file` per row: read that file for the full text.
`#tag` inside the query restricts to a tag. Without the CLI, read
`INDEX.md` at the root of the folder, then `tags/<tag>.md` or `YYYY-MM/INDEX.md`.

## Write

```sh
nutip add "https://example.com/post" -t reading -w "the pricing table"
nutip add "https://example.com/post" -t reading -x     # -x also fetches the page text
nutip add "some text" -t ideas -w "why it matters"     # or pipe text on stdin
```

Only use a tag from `nutip tags`; a new one is created silently and splits
their vocabulary. Always give `-w`: a clip without a reason is the one they
cannot use later.

## Clean up

The files are the truth; the index pages are generated and rewritten.

```sh
nutip rm 2026-09/2026-09-13-some-title.md    # trash one clip, indexes updated
nutip reindex                                # after editing any file by hand
```

To retag or fix a clip, edit the `tags:` or `why:` line in its frontmatter,
then `nutip reindex`. Never edit `INDEX.md`, `AGENTS.md`, `README.md`,
`tags/*.md` or `YYYY-MM/INDEX.md`: they start with a "generated by Nutip"
comment and are overwritten on the next save.

## Rules

- Do not bulk-delete or bulk-retag without asking: these are the user's own
  notes, and Nutip's undo only covers the last clip saved from the app.
- `nutip rm` trashes the file, it does not ask.
- Quote the `why` line when you report a clip back: it is why they kept it.
